# 《讓錢的事變簡單：打造伴侶與室友的私有記帳本》

歡迎閱讀本書。本專案提供一套基於 Google Workspace（Google 試算表 ＋ Google Apps Script）的自託管共同記帳解決方案，具備 **$0 運行成本、永久無廣告、資料自主掌控** 等特色。
