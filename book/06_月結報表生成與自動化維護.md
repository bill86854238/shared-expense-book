# 第 6 章：月結報表生成與自動化維護

## 1. 整合 Google Charts API 視覺化

系統前端無縫整合 Google 官方視覺化圖表庫（Google Visualization API），免安裝第三方套件即可繪製動態響應式財務報表：

```javascript
// 1. 載入 Google Charts 核心圖表套件
google.charts.load('current', {'packages':['corechart', 'line']});

// 2. 繪製消費分類分佈環形圖 (Donut Chart)
function drawCategoryChart(categoryStats) {
  const data = new google.visualization.DataTable();
  data.addColumn('string', '分類');
  data.addColumn('number', '金額');

  const rows = [];
  for (const [category, amount] of Object.entries(categoryStats)) {
    rows.push([category, Number(amount) || 0]);
  }
  data.addRows(rows);

  const options = {
    title: '本期消費類別佔比',
    pieHole: 0.45, // 環形設計
    colors: ['#8b5cf6', '#3b82f6', '#10b981', '#f59e0b', '#ef4444', '#ec4899', '#6b7280'],
    chartArea: { width: '90%', height: '80%' },
    legend: { position: 'bottom' },
    fontSize: 14
  };

  const chart = new google.visualization.PieChart(document.getElementById('category_chart_div'));
  chart.draw(data, options);
}

// 3. 繪製每月消費趨勢線圖 (Line Chart)
function drawMonthlyTrendChart(trendData) {
  const data = new google.visualization.DataTable();
  data.addColumn('string', '月份');
  data.addColumn('number', '總支出');
  data.addColumn('number', '你的部分');

  data.addRows(trendData); // [['1月', 15000, 7500], ['2月', 18000, 9000], ...]

  const options = {
    title: '年度月度支出趨勢',
    curveType: 'function', // 平滑曲線
    legend: { position: 'bottom' },
    chartArea: { width: '85%', height: '75%' },
    hAxis: { title: '月份' },
    vAxis: { title: '金額 (TWD)' }
  };

  const chart = new google.visualization.LineChart(document.getElementById('trend_chart_div'));
  chart.draw(data, options);
}
```

## 2. 自動化排程觸發器 (`ScriptApp.newTrigger`)

對於房租、水電費、電信費、串流影音等固定支出，系統透過 Apps Script 時間觸發器實現無人值守自動入帳：

```javascript
/**
 * 配置定時排程觸發器
 */
function setupTriggers() {
  // 清理現有觸發器，防止重複建立
  const triggers = ScriptApp.getProjectTriggers();
  triggers.forEach(trigger => ScriptApp.deleteTrigger(trigger));

  // 建立每日早上 9 點執行的時間觸發器
  ScriptApp.newTrigger('executeRecurringExpenses')
    .timeBased()
    .atHour(9)
    .everyDays(1)
    .create();

  Logger.log('已成功建立每日自動扣款排程觸發器');
}

/**
 * 每日定時執行的核心邏輯
 */
function executeRecurringExpenses() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const recurringSheet = ss.getSheetByName(CONFIG.SHEET_NAMES.RECURRING);
  if (!recurringSheet) return;

  const today = new Date();
  const currentDay = today.getDate(); // 取得今天幾號 (1~31)
  const data = recurringSheet.getDataRange().getValues();

  for (let i = 1; i < data.length; i++) {
    const [enabled, item, amount, payer, yourPart, partnerPart, category, executeDay, note] = data[i];

    // 若該項目已啟用且今天即為扣款日
    if (enabled === true && Number(executeDay) === currentDay) {
      addExpense(item, amount, payer, payer, yourPart, partnerPart, category, true, executeDay);
      Logger.log(`已自動新增週期支出：${item} - $${amount}`);
    }
  }

  // 更新最後執行時間戳記至設定表 B5
  const settingsSheet = ss.getSheetByName(CONFIG.SHEET_NAMES.SETTINGS);
  if (settingsSheet) {
    settingsSheet.getRange('B5').setValue(
      Utilities.formatDate(today, Session.getScriptTimeZone(), 'yyyy-MM-dd HH:mm:ss')
    );
  }
}
```

## 3. 常見問題排錯手冊 (38 題精選 FAQ SOP)

| 類別 | 常見故障現象 | 根本原因 | 標準排錯處置 SOP |
| :--- | :--- | :--- | :--- |
| **權限驗證** | 手機開啟網頁出現「🔒 無法存取」 | 存取者的 Google 帳號未加入試算表白名單 | 1. 試算表擁有者開啟試算表。<br>2. 切換至 `設定` 工作表。<br>3. 在 `B6` 儲存格以逗號加入該成員 Email。<br>4. 重新整理手機網頁即可進入。 |
| **部署發布** | 修改 Apps Script 程式碼後手機端未生效 | 部署時直接按儲存，未建立「新版本」 | 1. 開啟 Apps Script 編輯器。<br>2. 點選 `部署` → `管理部署`。<br>3. 點選右上角鉛筆圖示 (編輯)。<br>4. 版本選擇 **「新版本」**。<br>5. 點擊 `部署` 儲存。 |
| **分帳計算** | 送出記帳時跳出「分帳金額總和必須等於總金額」 | 手動輸入分帳金額時出現小數點四捨五入誤差 | 檢查 `你的部分` 與 `對方的部分`，確保兩者相加與總金額之差值 $\le 0.01$。 |
| **資料匯入** | 匯入 SettleUp 時提示「找不到試算表」 | 檔案未轉換為 Google 試算表或檔名不符 | 1. 將上傳的 CSV 於 Google 雲端硬碟中右鍵「以 Google 試算表開啟」。<br>2. 檔名重新命名為 `SettleUp_transactions`。<br>3. 確保與記帳本存放在同一雲端硬碟資料夾中。 |
| **週期扣款** | 每月 1 號房租沒有自動新增至支出記錄 | 時間觸發器遺失或 Google 授權過期 | 於試算表上方選單點選 `📊 記帳系統` → `⚙️ 進階設定` → `⏰ 手動設定觸發器` 重新註冊。 |
