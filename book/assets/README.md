## 💡 截圖與格式指引

1. **直式手機截圖**：
   * 在電腦 Chrome 瀏覽器打開記帳網頁，按 `F12` 開啟開發者工具，點選「手機模擬模式 (Toggle Device Toolbar)」，選擇 `iPhone 14/15 Pro` 即可截出清晰乾淨的手機直式介面。
2. **圖檔命名與儲存**：
   * 截圖完成後，直接存入本資料夾（`book/assets/`），並使用上方指定的英文檔名，書稿中的 Markdown 圖片連結即會自動呈現。
