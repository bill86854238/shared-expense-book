## 💡 截圖小訣竅 (Pro Tips)

1. **直式手機截圖（圖 02、03、04、06）**：
   * 在電腦 Chrome 瀏覽器打開記帳網頁，按 `F12` 開啟開發者工具，點選「手機模擬模式 (Toggle Device Toolbar)」，選擇 `iPhone 14/15 Pro` 即可截出乾淨的手機直式截圖。
2. **桌面/試算表截圖（圖 01、05、07）**：
   * 使用 macOS 快捷鍵 `Cmd + Shift + 4` 選取特定視窗或區域。
3. **儲存位置**：
   * 截圖完成後，請直接將檔案儲存於本資料夾（`book/images/`），並使用上方指定的檔案名稱（如 `01_mobile_interface.png`），書稿中的 Markdown 圖片連結即會自動生效。
