# 第 3 章：手機端極速記帳體驗與前端最佳化

## 1. PWA 與免安裝桌面捷徑架構

共同記帳的關鍵在於「結帳當下 3 秒內完成記錄」。若每次記帳都要在 App 商店下載更新或忍受冗長啟動畫面，將大幅降低記帳意願。本系統採用 Web App 免安裝架構，透過瀏覽器原生支援打造接近 Native App 的體驗：

- **iOS (Safari)**：點選底部分享按鈕 → 選擇 **「加入主畫面」**。系統啟動時會進入獨立無網址列視窗（Standalone Display Mode）。
- **Android (Chrome)**：點選右上角選單 → 選擇 **「新增至主畫面」** 或 **「安裝應用程式」**。

## 2. 行動端 UI/CSS 關鍵技術最佳化

### 16px 防自動縮放機制 (iOS Safari Auto-Zoom Bug)
在 iOS Safari 瀏覽器中，若表單輸入框 (`<input>`, `<select>`) 的字體小於 16px，系統會在使用者點擊輸入框時**強制放大頁面**，導致介面佈局跑版並遮蔽送出按鈕。

**解決方案**：在 CSS 中將基礎字體與所有輸入元件嚴格鎖定為 `16px`：

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Roboto", sans-serif;
  font-size: 16px; /* 基礎字體大小，確保行動端可讀性 */
  -webkit-text-size-adjust: 100%; /* 防止 iOS 自動調整字體 */
}

input, select {
  width: 100%;
  padding: 12px;
  border: 2px solid #d1d5db;
  border-radius: 8px;
  font-size: 16px !important; /* 嚴格禁止小於 16px 以杜絕自動放大 */
  background: white;
}
```

### 觸控熱區與防誤觸最佳化
根據行動裝置人機介面規範（Apple HIG），觸控目標最小不得小於 44x44 pt。本系統之按鈕與卡片均進行最佳化：

```css
.btn {
  padding: 14px 24px; /* 擴大點擊範圍 */
  min-height: 48px;
  border: none;
  border-radius: 10px;
  font-size: 16px;
  font-weight: 600;
  cursor: pointer;
  transition: all 0.3s ease;
}

/* 點擊時的動態回饋 */
.btn:active {
  transform: scale(0.98);
}

/* 非同步請求中的載入狀態動畫 */
.btn-loading {
  position: relative;
  color: transparent !important;
}
.btn-loading::after {
  content: "";
  position: absolute;
  width: 20px;
  height: 20px;
  top: 50%;
  left: 50%;
  margin-left: -10px;
  margin-top: -10px;
  border: 3px solid rgba(255, 255, 255, 0.3);
  border-radius: 50%;
  border-top-color: white;
  animation: spin 0.8s linear infinite;
}
```

## 3. 快速記帳按鈕自訂架構 (`getQuickExpenseButtons`)

為滿足日常高頻消費（如早餐、咖啡、交通捷運、超商），系統在 `設定` 工作表中提供可直接編輯的快速記帳矩陣（最多 12 組）：

```javascript
/**
 * 取得快速記帳按鈕設定（從試算表設定工作表動態讀取）
 */
function getQuickExpenseButtons() {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const settingsSheet = ss.getSheetByName(CONFIG.SHEET_NAMES.SETTINGS);

    if (!settingsSheet) return [];

    // 讀取第 10 列開始的快速記帳設定（最多 12 組）
    const data = settingsSheet.getRange(10, 1, 12, 4).getValues();
    const buttons = [];

    for (let i = 0; i < data.length; i++) {
      const [emoji, item, amount, category] = data[i];

      if (item && amount) {
        buttons.push({
          emoji: emoji || "📝",
          item: String(item).trim(),
          amount: Number(amount) || 0,
          category: String(category).trim() || "其他"
        });
      }
    }
    return buttons;
  } catch (e) {
    Logger.log("讀取快速記帳設定失敗: " + e.toString());
    return [];
  }
}
```

**前端動態綁定**：使用者在手機點擊「🍳 早餐 $50」時，前端 JavaScript 自動填入項目名稱、金額、分類並自動聚焦於付款人欄位，實現 1 秒極速送出。

## 4. 前端 XSS 防護與字串消毒機制

由於多成員輸入的文字會被儲存至試算表並重新渲染給所有成員，若未消毒可能遭受跨站腳本攻擊（Stored XSS）。後端嚴格採用字串轉義函式處理：

```javascript
/**
 * HTML 特殊字元編碼，防止 XSS 攻擊
 */
function escapeHtml(text) {
  if (!text) return "";
  return String(text)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#039;");
}
```
