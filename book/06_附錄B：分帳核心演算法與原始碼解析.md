## 1. 雙人結算抵銷演算法推導 (Net Balance Algorithm)

共同記帳的核心問題在於：**如何從大量交錯的代墊與分攤交易中，以 $O(N)$ 時間複雜度精確計算出當前的淨債權債務關係？**

### 數學模型推導
定義：
* $N$：歷史共同支出記錄筆數
* $A_{\text{your}}^{(i)}$：第 $i$ 筆交易「己方實際出資金額」
* $P_{\text{your}}^{(i)}$：第 $i$ 筆交易「己方應負擔的責任金額」
* $S_{\text{partner}\to\text{you}}$：對方主動向己方結算還款的累積總額
* $S_{\text{you}\to\text{partner}}$：己方向對方結算還款的累積總額

則己方的當前淨餘額 $\text{Balance}_{\text{your}}$ 運算式如下：

$$\text{Balance}_{\text{your}} = \sum_{i=1}^{N} \left( A_{\text{your}}^{(i)} - P_{\text{your}}^{(i)} \right) - S_{\text{partner}\to\text{you}} + S_{\text{you}\to\text{partner}}$$

### 餘額判定規則：
1. **$\text{Balance}_{\text{your}} > 0$**：己方累計出資大於消費責任，**對方應償還己方 $\text{Balance}_{\text{your}}$ 元**。
2. **$\text{Balance}_{\text{your}} < 0$**：己方累計出資小於消費責任，**己方應償還對方 $|\text{Balance}_{\text{your}}|$ 元**。
3. **$\text{Balance}_{\text{your}} = 0$**：雙方帳目完全平衡。

## 2. 外幣動態匯率與離線備援引擎

系統整合 Google 試算表的 `GOOGLEFINANCE` 函式，並在 Apps Script 後端構建靜態備援字典：

```javascript
/**
 * 取得指定外幣的換算匯率（對 TWD）
 * 優先從試算表讀取動態匯率，失敗時自動啟用預設備援匯率
 */
function getExchangeRate(currency) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const settingsSheet = ss.getSheetByName(CONFIG.SHEET_NAMES.SETTINGS);

    if (settingsSheet) {
      // 讀取設定表中的匯率矩陣（第 22 列開始）
      const rateData = settingsSheet.getRange(22, 1, 10, 3).getValues();

      for (let i = 0; i < rateData.length; i++) {
        const currencyCode = String(rateData[i][0]).trim();
        const rate = parseFloat(rateData[i][2]);

        if (currencyCode === currency && rate > 0) {
          return rate;
        }
      }
    }
  } catch (e) {
    Logger.log("從設定表讀取匯率失敗: " + e.toString());
  }

  // 離線靜態備援字典 (Fallback Rates)
  const defaultRates = {
    'JPY': 0.21,    // 日幣
    'USD': 31.5,    // 美金
    'EUR': 34.5,    // 歐元
    'HKD': 4.05,    // 港幣
    'CNY': 4.35,    // 人民幣
    'KRW': 0.024,   // 韓元
    'SGD': 23.5,    // 新加坡幣
    'GBP': 40.0,    // 英鎊
    'AUD': 20.5,    // 澳幣
    'THB': 0.92     // 泰銖
  };

  return defaultRates[currency] || 1.0;
}
```

## 3. 定時觸發器排程核心邏輯 (`ScriptApp`)

針對每月定期支出，系統配置每日執行的無伺服器排程：

```javascript
/**
 * 配置定時排程觸發器
 */
function setupTriggers() {
  const triggers = ScriptApp.getProjectTriggers();
  triggers.forEach(trigger => ScriptApp.deleteTrigger(trigger));

  // 建立每日早上 9 點執行的排程觸發器
  ScriptApp.newTrigger('executeRecurringExpenses')
    .timeBased()
    .atHour(9)
    .everyDays(1)
    .create();
}

/**
 * 每日定時執行的排程邏輯
 */
function executeRecurringExpenses() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const recurringSheet = ss.getSheetByName(CONFIG.SHEET_NAMES.RECURRING);
  if (!recurringSheet) return;

  const today = new Date();
  const currentDay = today.getDate();
  const data = recurringSheet.getDataRange().getValues();

  for (let i = 1; i < data.length; i++) {
    const [enabled, item, amount, payer, yourPart, partnerPart, category, executeDay] = data[i];

    if (enabled === true && Number(executeDay) === currentDay) {
      addExpense(item, amount, payer, payer, yourPart, partnerPart, category, true, executeDay);
      Logger.log(`已自動新增週期支出：${item} - $${amount}`);
    }
  }
}
```

## 4. 操作防護日誌工作表 (`logAction`)

為避免誤操作或多成員資料衝突，系統對關鍵寫入動作進行日誌追蹤，並使用 Google API 進行工作表權限鎖定：

```javascript
/**
 * 記錄操作日誌（敏感資訊脫敏與防篡改保護）
 */
function logAction(action, details) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let logSheet = ss.getSheetByName('操作日誌');

  if (!logSheet) {
    logSheet = ss.insertSheet('操作日誌');
    logSheet.getRange(1, 1, 1, 5).setValues([['時間', '使用者', '動作', '詳細資訊', '裝置識別']]);
    logSheet.getRange(1, 1, 1, 5)
      .setBackground('#1e293b')
      .setFontColor('#ffffff')
      .setFontWeight('bold');

    // 鎖定工作表：僅擁有者具備編輯權限
    const protection = logSheet.protect().setDescription('操作日誌防篡改保護');
    protection.removeEditors(protection.getEditors());
    protection.addEditor(ss.getOwner().getEmail());
  }

  logSheet.appendRow([
    Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy-MM-dd HH:mm:ss'),
    Session.getActiveUser().getEmail(),
    action,
    escapeHtml(String(details)),
    Session.getTemporaryActiveUserKey()
  ]);
}
```
