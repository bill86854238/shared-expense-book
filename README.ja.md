> **維持費0円・完全広告なし・データ完全所有**。カップル、同居人、ファミリー、個人の家計管理に最適です。

## ✨ 主な特徴

- 💰 **完全無料＆広告なし**：Google Workspace 上で稼働。サーバー費用やデータベース管理は一切不要です。
- 🔒 **プライバシー重視**：全データはお手持ちの Google ドライブ内に保存され、外部サーバーに送信されることはありません。
- 🎭 **個人・共同の2WAYモード切替**：
  - **個人モード**：収入と支出を個別に記録し、毎月の純収支を自動算出。
  - **共同モード**：均等割り、個別金額、割合指定、立替払いに柔軟対応。どちらが支払うべきかを自動計算。
- ⚡ **1秒クイック入力**：朝食、コーヒー、コンビニなどよく使う項目をワンタップで素早く記帳。
- ✈️ **旅行・外貨自動換算**：複数通貨の自動レート換算に対応し、旅行プロジェクトごとの独立集計が可能。
- ⏰ **固定費の自動記帳**：家賃、光熱費、サブスクリプションなどを毎月指定日に自動記帳。
- 🎨 **4種類のデザインテーマ**：上品なパープル、爽やかなグリーン、明るいコーラル、落ち着いたネイビー。
- 📥 **データ移行とバックアップ**：SettleUp や AndroMoney からのインポート対応。Excel / CSV 形式でいつでもダウンロード可能。
- 🛡️ **安全性の確保**：XSS 対策、クリックジャッキング対策、レートリミット、Google アカウントによるアクセス制限。

## 🎯 ご利用シーン

- **同棲カップル・夫婦**：日々の生活費、外食の割り勘、家賃・光熱費の精算に。
- **ルームシェア**：共有生活費の透明化とスムーズな精算。
- **家族の家計簿**：家族全体の収支管理と固定費の自動化。
- **旅行の割り勘**：旅行ごとの個別集計と外貨建てのレシート管理。
- **個人の収支管理**：給与、ボーナス、日々の支出記録。

## 🚀 はじめ方 (Copy & Play)

**わずか 2 ステップ** でスマホから利用開始できます：

1. **テンプレートをコピー**：  
   👉 [スプレッドシートのコピーを作成](https://docs.google.com/spreadsheets/d/1ZEXa0R0MGEMyG9W-Rh2t7bj1HCeM-gJ0chN7qqDw054/copy)
2. **初期化とウェブアプリのデプロイ**：
   - コピーしたシートを開き、上部メニューの **`📊 記帳系統` → `1️⃣ 第一步：初始化系統`** をクリック（シート構成と定期実行トリガーを自動生成）。
   - **`拡張機能` → `Apps Script` → 右上の `デプロイ` → `新しいデプロイ`** を選択（種類: ウェブアプリ、実行ユーザー: 自分、アクセス権: 全員）。生成された URL をスマホのブラウザで開くだけで完了です！

> 💡 **ポイント**：People API の有効化や手動でのトリガー設定は一切不要です。

詳しい使い方やよくある質問は [FAQ.md](./FAQ.md) をご覧ください。

## ❓ よくある質問

- **Q: テンプレートをコピーすると、他の人にデータが見られますか？**  
  **A:** いいえ。完全に独立したシートがご自身の Google ドライブに作成されるため、他人が閲覧することはできません。
- **Q: パートナーや同居人を招待するには？**  
  **A:** `設定` シートの `B6` セルに相手の Google メールアドレスを入力し、ウェブアプリの URL を共有してください。
- **Q: データのバックアップは可能ですか？**  
  **A:** はい。スプレッドシートの「ファイル → ダウンロード」から Excel や CSV 形式でいつでも保存できます。
