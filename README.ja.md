# 💑 共有家計簿・割り勘管理システム (Shared Expense Book)

🌐 **言語 / Language / 語言**: [繁體中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

> Google Apps Script と Google スプレッドシートを活用した、完全無料・プライベートな共有家計簿アプリ。  
> **月額費用0円・広告なし・データ完全所有。** 同棲カップル、夫婦、ルームシェア、個人の収支管理に最適です。

## ✨ 主な特徴

- 💰 **ずっと無料＆広告なし**：Google Workspace 上で動作するため、サーバー代や維持費は永久に0円。わずらわしい広告も一切ありません。
- 🔒 **自分のアカウントで完全管理**：データはご自身の Google アカウント内に直接保存されます。開発者のサーバーや外部サービスを経由しないため、情報の転売や広告追跡の心配がありません。
- 🎭 **個人用と共有用をワンタッチ切り替え**：
  - **個人家計簿モード**：毎月の給与・副収入と支出を分けて記録し、手残り（純貯蓄）を自動計算。
  - **共有割り勘モード**：完全折半（50:50）、指定金額、割合分担、全額立て替えに対応。「いま誰がいくら払うべきか」を常に自動精算。
- ⚡ **1秒で終わるワンタップ記帳**：朝食、カフェ、交通費、コンビニなど、よくある支出をボタンひとつで即座に入力。
- ✈️ **海外旅行・外貨レート自動換算**：複数通貨をリアルタイムレートで自動換算。旅行ごとのタグ別集計もラクラク。
- ⏰ **固定費の自動記帳（定期実行）**：毎月の家賃、光熱費、サブスクなどを指定日に自動で記帳。
- 🎨 **気分で選べる4色のデザインテーマ**：上品なパープル、爽やかなグリーン、明るいコーラル、落ち着いたネイビー。
- 📥 **他社アプリからの乗り換え＆CSV書き出し**：SettleUp や AndroMoney の履歴インポートに対応。いつでも Excel / CSV で手元にバックアップ可能。
- 🛡️ **安心のセキュリティ対策**：XSS 対策、クリックジャッキング対策、Google アカウントによるアクセス制限（ホワイトリスト制御）。

## 🎯 ご利用シーン

- **同棲カップル・夫婦**：日々の生活費、外食の割り勘、家賃・光熱費の精算に。
- **ルームシェア**：共有生活費の透明化とスムーズな精算。
- **家族の家計簿**：家族全体の収支管理と固定費の自動化。
- **旅行の割り勘**：旅行ごとの個別集計と外貨建てのレシート管理。
- **個人の収支管理**：給与、ボーナス、日々の支出記録。

## 🚀 はじめ方 (Copy & Play)

**わずか 2 ステップ** でスマホから使い始められます：

1. **テンプレートをコピー**：  
   👉 [スプレッドシートのコピーを作成](https://docs.google.com/spreadsheets/d/1ZEXa0R0MGEMyG9W-Rh2t7bj1HCeM-gJ0chN7qqDw054/copy)
2. **初期化とウェブアプリのデプロイ**：
   - コピーしたシートを開き、上部メニューの **`📊 記帳系統` → `1️⃣ 第一步：初始化系統`** をクリック（シート構成と定期実行トリガーを自動生成）。
   - **`拡張機能` → `Apps Script` → 右上の `デプロイ` → `新しいデプロイ`** を選択（種類: ウェブアプリ、実行ユーザー: 自分、アクセス権: 全員）。生成された URL をスマホのブラウザで開くだけで完了です！

> 💡 **ポイント**：People API の有効化や手動でのトリガー設定は一切不要です。

詳しい使い方やよくある質問は [FAQ.md](./FAQ.md) をご覧ください。

## ❓ よくある質問

- **Q: テンプレートをコピーすると、他の人にデータが見られますか？**  
  **A:** いいえ。完全に独立したシートがご自身の Google ドライブに作成されるため、他人が閲覧することはできません。
- **Q: パートナーや同居人を招待するには？**  
  **A:** `設定` シートの `B6` セルに相手の Google メールアドレスを入力し、ウェブアプリの URL を共有してください。
- **Q: データのバックアップは可能ですか？**  
  **A:** はい。スプレッドシートの「ファイル → ダウンロード」から Excel や CSV 形式でいつでも保存できます。
