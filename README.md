## ✨ 核心特色

- 💰 **永久免費與無廣告**：基於 Google Workspace 雲端生態系，無需租用伺服器或資料庫。
- 🔒 **資料 100% 私有掌控**：所有帳目均保存在您個人的 Google 雲端硬碟，絕不上傳至任何第三方中繼主機。
- 🎭 **個人／共同雙模式無縫切換**：
  - **個人記帳**：收入與支出分軌統計，自動計算每月淨結餘。
  - **共同分帳**：支援平分、自訂金額、比例分配與代墊全額負擔，智慧結算誰該付錢。
- ⚡ **一秒日常快捷記帳**：自訂早餐、咖啡、超商等常用按鈕，一鍵秒速入帳。
- ✈️ **出國旅遊與外幣即時換算**：支援多國貨幣自動換算為新台幣，並可透過專案標籤獨立打包旅費。
- ⏰ **固定支出自動排程**：房租、水電、定期訂閱服務每月定時自動扣款。
- 🎨 **四款質感主題配色**：優雅紫、清新綠、活力橘紅、商務藍，自動記憶偏好設定。
- 📥 **無痛匯入舊帳與自由匯出**：相容 SettleUp 與 AndroMoney 歷史資料，隨時可下載 Excel (.xlsx) / CSV 完整備份。
- 🛡️ **生產級安全防護**：全面修復 XSS 攻擊防護、CSRF / 點擊劫持防範、請求頻率限制與 Google 白名單權限控管。

## 🚀 快速開始 (Copy & Play)

現在部署已全面簡化，只需 **2 個步驟** 即可在手機上啟用：

1. **一鍵複製試算表範本**：  
   👉 [點我建立試算表副本](https://docs.google.com/spreadsheets/d/1ZEXa0R0MGEMyG9W-Rh2t7bj1HCeM-gJ0chN7qqDw054/copy)
2. **兩步初始化與發布**：
   - 開啟複製後的試算表，點擊頂部選單 **`📊 記帳系統` → `1️⃣ 第一步：初始化系統`**（自動建立工作表與定時排程觸發器）。
   - 點擊 **`擴充功能` → `Apps Script` → 右上角 `部署` → `新部署`**（選擇網頁應用程式，執行身分：我，存取權限：所有人），複製產生的網址即可在手機瀏覽器開啟使用！

> 💡 **小叮嚀**：本系統已全面優化核心架構，**無需手動啟用 Google People API 或設定觸發器**，開箱即可直接使用。

## ❓ 常見問題

- **Q: 別人複製後會看到我的帳目嗎？**  
  **A:** 完全不會。每個人複製的是獨立的試算表與程式碼，資料完全儲存在各自的 Google 雲端硬碟中。
- **Q: 如何邀請另一半或室友共同記帳？**  
  **A:** 開啟試算表的 `設定` 工作表，在儲存格 `B6` 填入對方的 Gmail 信箱，並將手機網頁網址分享給對方即可。
- **Q: 資料可以備份嗎？**  
  **A:** 可以，隨時可於試算表點選「檔案 → 下載」匯出為 Excel 或 CSV 檔案。
